## HOUR 3: SET UP (45 min)

### Platform Setup (Gumroad — Fastest):
```
1. gumroad.com → "Start Selling"
2. Create account → Verify email
3. "New Product" → Upload files
4. Set price → Write description
5. Connect Stripe/PayPal
6. Create discount: LAUNCH30 = 30% off
```

### Sales Page Formula:
```
HEADLINE: [Result] + [Timeframe]
PROBLEM: 2-3 sentences about pain
SOLUTION: What's inside (bullet list)
BONUSES: Extra value included
PRICE: Show original crossed out, sale price
GUARANTEE: 30-day money-back
CTA: "Get Instant Access"
```
