## Contract Architecture

Space Rocks uses a modular smart contract architecture for security and upgradability.

## Main Contracts

### NFT Contract (ERC-721)

**Purpose**: Manages rock NFT minting, transfers, and metadata

**Key Functions**:
```solidity
function mint(uint256 rockId, string memory metadata) external
function burn(uint256 tokenId) external
function stake(uint256 tokenId) external
function unstake(uint256 tokenId) external
```

### Staking Contract

**Purpose**: Handles NFT staking and reward distribution

**Features**:
- Automatic reward calculation
- Compound staking option
- Emergency withdrawal
- Tiered APY by rarity

### Marketplace Contract

**Purpose**: Facilitates peer-to-peer NFT trading

**Features**:
- Fixed price listings
- Auction system
- Offer mechanism
- Royalty enforcement
