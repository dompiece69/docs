## Web3 Integration Guide

Connect your application to Space Rocks smart contracts and blockchain features.

## Setup

```bash
npm install @spacerocks/web3-sdk ethers
```

## Initialize

```javascript
import { SpaceRocksWeb3 } from '@spacerocks/web3-sdk';
import { ethers } from 'ethers';

const provider = new ethers.providers.Web3Provider(window.ethereum);
const signer = provider.getSigner();

const spaceRocks = new SpaceRocksWeb3({
  provider,
  signer,
  network: 'polygon'
});
```

## Smart Contract Interaction

### Mint NFT

```javascript
// Mint a rock as NFT
const tx = await spaceRocks.nft.mint({
  rockId: 'rock_123',
  metadata: {
    name: 'Epic Fire Rock',
    description: 'Collected at Eiffel Tower'
  }
});

await tx.wait();
console.log('NFT minted!', tx.hash);
```

### Stake NFT

```javascript
// Stake NFT for rewards
const tx = await spaceRocks.staking.stake({
  tokenId: 123,
  lockPeriod: 30 // days
});

await tx.wait();
```

### Trade on Marketplace

```javascript
// List NFT for sale
const tx = await spaceRocks.marketplace.list({
  tokenId: 123,
  price: ethers.utils.parseEther('10') // 10 tokens
});

await tx.wait();
```
