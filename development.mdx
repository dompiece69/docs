## Developer Resources

Welcome to the Space Rocks developer documentation. Build integrations, tools, and applications using our APIs and SDKs.

## Quick Start

<Steps>
  <Step title="Get API Key">
    Register at [developer.spacerocks.game](https://developer.spacerocks.game) to get your API key
  </Step>
  
  <Step title="Choose SDK">
    Select the SDK for your platform (JavaScript, Python, Unity, etc.)
  </Step>
  
  <Step title="Install SDK">
    Install via package manager or download directly
  </Step>
  
  <Step title="Authenticate">
    Initialize SDK with your API key
  </Step>
  
  <Step title="Start Building">
    Make your first API call
  </Step>
</Steps>

## Example: Fetch Nearby Rocks

<Tabs>
  <Tab title="JavaScript">
    ```javascript
    import { SpaceRocksSDK } from '@spacerocks/sdk';

    const sdk = new SpaceRocksSDK({
      apiKey: 'your_api_key_here'
    });

    // Get rocks near a location
    const rocks = await sdk.rocks.getNearby({
      latitude: 40.7128,
      longitude: -74.0060,
      radius: 1000 // meters
    });

    console.log(`Found ${rocks.length} rocks nearby`);
    ```
  </Tab>
  
  <Tab title="Python">
    ```python
    from spacerocks import SpaceRocksSDK

    sdk = SpaceRocksSDK(api_key='your_api_key_here')

    # Get rocks near a location
    rocks = sdk.rocks.get_nearby(
        latitude=40.7128,
        longitude=-74.0060,
        radius=1000  # meters
    )

    print(f"Found {len(rocks)} rocks nearby")
    ```
  </Tab>
  
  <Tab title="cURL">
    ```bash
    curl -X GET "https://api.spacerocks.game/v1/rocks/nearby" \
      -H "Authorization: Bearer your_api_key_here" \
      -H "Content-Type: application/json" \
      -d '{
        "latitude": 40.7128,
        "longitude": -74.0060,
        "radius": 1000
      }'
    ```
  </Tab>
</Tabs>

## Authentication

All API requests require authentication:

```javascript
// Header-based authentication
headers: {
  'Authorization': 'Bearer YOUR_API_KEY',
  'Content-Type': 'application/json'
}
```
