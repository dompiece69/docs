## NFT Backing System

Every minted NFT locks $ROCK tokens as backing:

### Backing Amounts

| Rarity | Locked $ROCK | Retrievable |
|--------|-------------|-------------|
| Common | 10 | ✅ Yes (burn NFT) |
| Uncommon | 50 | ✅ Yes (burn NFT) |
| Rare | 200 | ✅ Yes (burn NFT) |
| Epic | 1,000 | ✅ Yes (burn NFT) |
| Legendary | 5,000 | ✅ Yes (burn NFT) |
| Mythic | 25,000 | ✅ Yes (burn NFT) |

<Note>
  Burning an NFT returns the locked $ROCK to your wallet, but destroys the NFT permanently.
</Note>

### Why Backing Matters

- **Intrinsic Value**: Every NFT has a minimum value floor
- **Price Stability**: Prevents NFT prices from falling below backing amount
- **Deflationary**: Burning NFTs removes $ROCK from circulation
- **Trust**: Transparent, verifiable backing on-chain

## Token Economics

### Supply Dynamics

<AccordionGroup>
  <Accordion title="Inflationary Mechanisms" icon="arrow-up">
    **New $ROCK enters circulation through:**
    - Play-and-earn rewards
    - Staking rewards
    - Quest completions
    - Event rewards
    
    **Controlled by:** Emission schedule with decreasing rates over time
  </Accordion>
  
  <Accordion title="Deflationary Mechanisms" icon="arrow-down">
    **$ROCK is removed from circulation through:**
    - NFT backing (locked)
    - NFT burning (permanent removal)
    - Evolution costs (burned)
    - Marketplace fees (burned)
    
    **Effect:** Reduces circulating supply over time
  </Accordion>
</AccordionGroup>

### Emission Schedule
