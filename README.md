# Space Rocks Documentation

> Official documentation for Space Rocks - A play-and-earn mobile game that integrates real-world exploration with digital collectible NFTs.

## 🚀 About Space Rocks

Space Rocks is a revolutionary play-and-earn mobile game that bridges the physical and digital worlds. Players explore real-world locations to discover geo-located rocks, mint them as NFTs, and watch them evolve into rare cosmic artifacts backed by our native meme coin ($ROCK).

## 🛠️ Local Development

### Prerequisites
- Node.js 18+ or Bun
- npm, yarn, or pnpm

Install the Mintlify CLI:

```bash
npm i -g mint
```


## 📖 Key Features Documented

### Game Mechanics
- **Real-World Exploration**: GPS-based rock discovery system
- **Evolution System**: Transform rocks from simple stones to quantum entities
- **Rarity Tiers**: 6 tiers from Common (60% drop) to Mythic (0.1% drop)
- **Element Types**: Fire, Water, Earth, Air, and Cosmic elements
- **Play-and-Earn**: Multiple earning mechanisms including staking, trading, and quests

### NFT System
- **Multi-Chain Support**: Polygon, Base, Ethereum, BSC, Arbitrum
- **NFT Backing**: Every NFT backed by locked $ROCK tokens
- **Staking Rewards**: Up to 15% daily APY for Mythic NFTs
- **Marketplace**: Zero fees for Legendary+ holders

### Tokenomics
- **Token**: $ROCK (ERC-20)
- **Total Supply**: 1,000,000,000
- **Distribution**: 30% play-and-earn, 25% NFT backing, 20% liquidity
- **Deflationary**: Burns through evolution, minting, and marketplace fees
