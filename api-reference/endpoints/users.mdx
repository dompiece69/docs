## Users Endpoints

The Users API provides access to user profiles, inventory, and statistics.

## Get User Profile

```http
GET /api/v1/users/:user_id
```

Get detailed user profile information.

### Response

```json
{
  "success": true,
  "user": {
    "id": "user_123",
    "username": "RockCollector",
    "level": 25,
    "experience": 125000,
    "wallet_address": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
    "stats": {
      "rocks_collected": 1250,
      "nfts_minted": 45,
      "total_earnings": "15000.50",
      "countries_visited": 5
    },
    "created_at": "2025-01-01T00:00:00Z"
  }
}
```

## Get User Inventory

```http
GET /api/v1/users/:user_id/inventory
```

Get user's rock inventory.

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| page | integer | Page number (default: 1) |
| limit | integer | Items per page (default: 20, max: 100) |
| rarity | string | Filter by rarity |
| element | string | Filter by element |

### Response

```json
{
  "success": true,
  "inventory": [
    {
      "id": "rock_abc123",
      "rarity": "rare",
      "element": "fire",
      "power": 250,
      "minted": false,
      "collected_at": "2025-11-04T12:00:00Z"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 150,
    "pages": 8
  }
}
```
